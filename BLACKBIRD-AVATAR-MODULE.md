# Blackbird Avatar Module

Start with [the embodiment blueprint](embodiment/README.md).

This branch adds an embodiment extension to existing Blackbird. The core registry remains `blueprint.json`; the extension registry is `embodiment/avatar-blueprint.json`. Read both, applying the explicit [September 12 autonomy amendment](embodiment/AUTONOMY-AMENDMENT.md) and [integration mapping](embodiment/INTEGRATION.md) where older documents conflict.

The extension replaces the September 12 standalone companion-runtime proposal as the implementation handoff for avatar work. It retains semantic motion, voice, assets, snapshots, and feedback while reusing Blackbird's core, cognition, memory, and action boundaries.

Publication of this blueprint does not start implementation. The next step is to locate Bill's existing first-slice checkout, map its real interfaces, and attach one visible body with one working gesture and a receipt.
