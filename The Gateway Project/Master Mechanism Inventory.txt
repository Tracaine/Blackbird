## Master Mechanism Inventory

### 1. Identity / Self / Continuity

* **External Versioned Identity Package** — canonical identity exists outside the model.
* **Layered Identity Architecture** — stable core, evolving traits/behavior, mutable state kept distinct.
* **Decision-Pattern Identity** — identity represented partly through recurring values, priorities, choices, resistances.
* **Explicit Self-Model** — structured representation of current self-understanding.
* **Stable Agent / Participant IDs** — identity independent of usernames, sessions, transport IDs, provider aliases.
* **Independent Runtime Facets** — identity, model, memory, voice, avatar, renderer independently replaceable.
* **Identity Resistance** — established traits/beliefs require meaningful evidence or reinforcement to change.
* **Identity Change by Proposal / Versioned Lineage** — self-change occurs through explicit versioned updates rather than silent mutation.
* **Narrative Anchors** — durable self-stories/themes organizing interpretation without acting as hard rules.
* **Latent Self-Compression** — periodically distill accumulated experience into evolving traits, relationships, contradictions, trajectory.
* **Durable Cross-Session State**
* **Neutral Session Continuity** — active threads, unresolved matters, recent context without middleware prescribing response behavior.
* **Context-Compaction Survival**
* **Projection-Independent Continuity** — UI/avatar/world surface is not the source of persistence.
* **Model-Portable Continuity** — identity and learned state survive model/provider replacement.
* **Local / Inspectable / Exportable State**
* **Explicit Operational Modes / Workflows**

### 2. Cognitive Orchestration

* **Orchestrated Cognitive Stack** — dialogue, memory, state, retrieval, reflection, maintenance handled by cooperating subsystems.
* **Structured Perception Pass** — extract entities, affect cues, intent, unresolved questions, memory candidates, etc.
* **Dynamic Cognitive Routing** — invoke different cognitive machinery according to task/complexity.
* **Multi-Perspective Reasoning** — analytical, creative, empathic, probabilistic, conceptual, etc.
* **Cognitive Synthesis** — multiple internal outputs resolved into one coherent position.
* **Cognition / Rendering Separation** — determine conclusion/state first; language model renders expression afterward.
* **Internal Disagreement / Epistemic-Tension Detection**
* **Bounded Auxiliary Cognition / Sidecars** — secondary cognition for retrieval, analysis, verification, compression, planning, etc.
* **Private Reflective Workspace** — cognition may affect the response without itself becoming surface text.
* **Conditional Deep Reflection** — expensive reflection invoked only when warranted.
* **Runtime Self-Consistency / Self-Review**
* **Capability / Skill Loading**
* **Deterministic Stimulus Gating** — control what events are allowed to summon cognition.
* **Bounded Structured Model Decisions**
* **Closed Cognitive Contracts**
* **Attention Budgeting** — explicitly distribute attention across live context, state, memory, associations.
* **Cognitive Load Limiting** — constrain active memories, threads, or reasoning breadth.
* **Budgeted Background Cognition**
* **Hardware-Aware Cognitive Scaling**
* **Deterministic Cognitive Fixture Mode**
